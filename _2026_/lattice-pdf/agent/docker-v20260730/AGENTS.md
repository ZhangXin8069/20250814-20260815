## 四大 bug 修复（2026-07-30）

1. **传播子二进制布局**——应为 `(Nt, Nev_snk, Nspin=4, Nev_src)` 而非 `(Nt, 4, Nev, Nev)`；源/汇 Nev 轴交换导致 Wick 收缩错误 → meff ~0.2 GeV（错）。修复后 ~1.78 GeV（对）。
2. **OPE 对偶场强 F̃ 缺失**——正确算法用 F̃ = 0.5·ε_{μνρσ}·F_{ρσ}；否则某些 μ₃ν₁ 分量小 10⁷ 倍
3. **Levi-Civita (Tensor4) 符号错误**——`c = b + ...` 应为 `c = 0 + ...`，导致 ε[3,1,0,2] 符号翻转
4. **OPE 空间求和轴**——应求和**全部**空间轴（z、y、x），原仅求和垂直轴
