# AGENTS.md — docs

80 篇已发表格点 QCD 研究论文（PDF，只读参考库，胶子 PDF 项目主要文献集）。

## 使用

```bash
pdftotext "论文名.pdf" - | head -100   # 提取文本
```

## 论文分类
